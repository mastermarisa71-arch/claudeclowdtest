# 第1話 v2 修正版

開くファイル：`EP01_v2.prproj`（Premiere Pro 2025で保存済み）。素材フォルダはこの場所のまま保管してください。

## シーケンス
- `EP01_v2_24fps`：全194配置、5分25秒17フレーム。
- `EP01_v2_Short_24fps`：任意カットを省いた190配置、5分19秒02フレーム。S2-11①②、S4-12①②を省き、S3-14①の任意台詞を外しています。

いずれも24fps、1920×1080。新しいv2の番号と並べ順に更新し、S9をS8の前に置きました。タイトルと〈つづく〉を含みます。

## 反映内容
- 提供された9コマプロンプトを16シート分生成し、140コマを切り出し。指定の既存52コマを再使用。
- 新しいキャラクター資料と背景資料を確認して添付。シート間の参照は生成済みシートを使用。
- 黒板2箇所とメモに「チョコパン」を合成。
- 指定の5箇所に0.3秒のディゾルブ。フォロー、振り、ワイプはカットで接続。S7-04は8度傾け、指定の寄り・引きのみスケールのキーフレームを設定。
- 音声は70箇所を再利用し、12箇所を新規生成。長い台詞は最大120％まで調整し、収まらない分はカットを延長。
- 既存の劇伴・SEから64クリップを映像に合わせて再配置。S7-01で劇伴を止め、「大丈夫そうね」の台詞終了後に戻しています。
- 下中央に字幕、左上にカット番号。上中央のタイムコードはPremiereの「メタデータとタイムコードの焼き込み」エフェクト。V3の全尺レイヤーから変更できます。
- 台詞、音楽、SEは別クリップで調整可能。字幕とカット番号はV2の透過PNG、文字入り黒板・メモは静止画に合成されています。

## 確認用
`EP01_v2_review.mp4` と `EP01_v2_Short_review.mp4` は960×540の確認用動画です。
新しいシーケンスの参照素材は全て存在確認済み。音声ソースはモノラル48kHz WAVに統一し、以前のチャンネル数不一致を避けています。確認用ミックスのピークは約-3.76dBFS。
