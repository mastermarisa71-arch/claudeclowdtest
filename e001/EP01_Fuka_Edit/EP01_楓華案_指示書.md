# EP01 楓華案 指示書（新規で映像を作り、v6と比べる用）

## 1. この版について
楓華さんの字コンテ（EP01 演出案 v1）の111カットを、全部**新規生成**のコマに割ったものです。前の画像は使いません。
- 新規に生成するコマ：180コマ（20シート）。タイトルと最後の黒は後載せ。
- 尺：約319.2秒（5分19.2秒）。字コンテの仮尺どおり。上映順：S1→S2→タイトル→S3→S4→S5→S6→S7→S9（閉店後のノート）→S8→〈つづく〉
- カメラは字コンテのとおり**基本は固定**。動くのはS1-02（平行に追う）、S1-08（後ろから追って止まる）、S3-02（注ぐ手からミドルへ）、S5-10②（視線に沿って一度だけパン）。
- 同じカットの①②③は、同じ画角で芝居だけが変わるコマ（「芝居と配置」の流れを2〜3コマに分けた）。

## 2. 画面の方向
- 暁は**左→右**（右＝店の側）。捜査官は**右→左**（店の側から町へ）。字コンテの「右から左」「左から右」は、扉の向きのコメントで直したラインに合わせて逆にしています。
- 入口の内側：扉が左、店が右。

## 3. 台詞（字コンテの仮改稿を使用）
- S3-11 まひる「でもさ、外じゃ、こんなこともできないんだよね」
- S4-03 朔奈（OFF）「外では、大人しくしてた？」
- S5-05 まひる「……三禁って、いつまで続くんだろうね。ほんっと、つまんない町になったよねー」
- S7-13 あかね「ほんと、心臓止まるかと思いました……」、S7-14 まひる「はぁー……やばかったんだけどー……！」
- S8-11 は「……ここはマークしておけばよい」まで（「まっ、そのときには……な？」はなし）

## 4. 文字の合成
- 黒板（S1-03、S8-10）、メモ（S2-04）は同じ言葉「チョコパン」を編集で合成。ノート（S9-02）は「今日も、誰も捕まらなかった。」。
