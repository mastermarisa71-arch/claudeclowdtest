字コンテから9コマ生成、並べ、動画化するまでの決まりごと。

## 9コマ生成

- 1シート＝16:9 を 3×3 に等分した 9コマ。シートは必ず9コマ埋める（新規コマ数は9の倍数にそろえる）。
- 参照画像の添付順は全話共通：背景 → 店内配置図 → あかね → 朔奈 → まひる → 海凪 → 暁 → おばあ → ステラ → 先輩 → 後輩 → ゲスト。構図をそろえる「参考」画像は最後。
- 画像の保存名：`EP01_v6_sh{シート2桁}_k{コマ番号}.png`（版ごとに接頭辞を変える）。
- 前の画像を使い回すのは、構図・芝居・配置・光が同じときだけ。似ているだけなら新規にする。
- コマ内に文字を描かない。黒板・メモ・手帳・ノートの文字は編集で合成し、観客が読めるようにする。

## カメラワーク

- カメラの動き（付けパン、回り込み、T.U./T.B.、振り、ピン送り、回転、クレーン）は、コマを始点・終点のキーフレームとして描き、動画生成でつなぐ。字コンテの「動画化」の列にどのコマからどのコマへどう動くかを書く。
- 動画生成で破綻するときは 0.3秒のディゾルブでつなぐ。編集で足すのは小さな拡大縮小、回転、ディゾルブだけ。
- 会話は二人・三人を同じ画に入れ、台詞の途中で聞き手へ移る（切る・振る）。

## 画面の方向

- 店（扉の内側）＝画面の右、外（町）＝左。外の暁は右を向いて左→右へ進み、扉の内側のあかねは左を向く。捜査官は右→左。
- 店内はカウンターの天板を軸に、客席の側（A・C・D・E）から撮る。カウンターの内側（B）から撮るときは「Aと左右が反転」と書く。

## キャラと小物

- カクテルを作り、シェイカーを振るのは朔奈だけ。まひるは料理（泡立て器、絞り袋）。
- ステラは全身真っ黒（足先・尻尾の先も黒）。
- 先輩の紋章は左腕。左右反転で使うと右腕になるので注意。
- SD・イメージBGは日常のギャグだけ。緊張、安堵、感情の場面は通常の頭身で描く。
- 黒の主線（#000000）を使わない。

## 資料の置き場所

- プロンプト・字コンテ・並べ順リスト・指示書：ファイル（md / xlsx / csv）。
- 一緒に設計するもの：Claude Docs で作業し、まとまったらこの vault に書き出す。
