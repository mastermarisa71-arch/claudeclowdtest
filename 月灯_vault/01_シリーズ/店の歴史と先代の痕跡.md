月灯りが「おじいちゃんの代から続く酒場」だと分かるための設定と、店内に置いた品の一覧。美術・コンテ・脚本で古さを出すときは、ここを見る。

## 店の歴史

- 月灯りは、先代（おじいちゃん）と奥さん（おばあ）が開いた店。おばあが表でパン屋をしながら、裏でおじいちゃんが酒場をしていた。開店の日の客は12人。
- おばあは、今もパン屋の店主（表の顔）。2話の「孫と、その友だち」は、朔奈とその仲間のこと。
- 先代の頃は常連でにぎわい、ピアノと蓄音機で音楽が流れていた。
- おじいちゃんが亡くなり、裏の店は閉じて、埃をかぶった空き部屋になっていた。3年前、孫の朔奈がおじいちゃんの思いを引き継ぎ、仲間と改装して、潜り酒場として続けている（5話）。
- 朔奈たちは、先代の品をほとんど捨てずに使っている。新しく揃えたものより、受け継いだものの方が多い店。
- ステラは、もともと先代夫婦が飼っていた猫。全身黒。
- 先代夫婦の写真の奥さんは、若い頃・年を重ねた頃のおばあ。おばあのデザインが決まったら、写真の顔を合わせて描き直す。

## メニュー：先代の味を、まひるが再現している

今のメニューは新しく作ったものではなく、ほとんどが先代の頃の品書き。まひるが、厨房の壁に残っていた先代のレシピと、常連の記憶を頼りに味を再現した。メニューの文字や中身は「古いものが多い店」に寄せる。

| 品 | 由来 | 店内の手がかり |
| --- | --- | --- |
| 月灯り（看板のカクテル） | 先代が考えた一杯。今は朔奈が作る | カウンターのレシピ帳の「月灯り」のページ |
| ナポリタン | 先代のレシピ。まひるが再現 | 厨房の壁のレシピ |
| ポテトサラダ | 同上 | 同上 |
| オムレツ | 同上 | 同上 |
| 自家製ピクルス | 同上 | 同上 |
| ミートパイ | 同上 | 同上 |
| レモンの蜂蜜漬け | 同上 | 同上 |
| 月灯りのクッキー | 同上 | 同上 |
| まかないカレー | 先代のまかない。メニューには載せない裏の一品 | 同上 |
| アフォガード、デザート類 | まひるが加えた、今の代の品 | ― |

- 品書きの見せ方の案：先代からの品に小さな月の印をつける、黒板の端に「先代の味」と書く、など。黒板・メニューカードの絵を描き直すときに入れる。
- レシピの中の「ばあさんの味」「塩ひとつまみ」などの書き込みは、まひるが再現で迷う手がかりとして使える。

## 3Dでは作らず、アニメの寄りで描くもの

背景美術にいつも描くとくどくなるので、寄りのカットで「そこに残っている」と見せる。

- 柱の背比べの傷（朔奈たちが小さい頃の線と日付）
- テーブル・カウンターのグラスの跡、角の擦れ、小さな彫り込み
- 先代の頃からの床の傷、椅子の脚の跡

## まだ置いていない案

- 先代の頃の古いメニューを額に入れて、今の黒板の隣に
- ボトルキープの札の一部を、もう来なくなった常連の名前のまま残す（寄せ書きとつなげる）
