# 2話 絵コンテ修正案（v6・新しい2話脚本）

Oct 10, 2026

## 方針

新しい2話の脚本（10/9 書き直し版）を、v5の字コンテ（EP02\_字コンテ\_v5・約4分）の素材をなるべく使い回して組み直す案です。全79カットのうち、v5流用18・修正（画は流用し、台詞や芝居を差分で直す）42・新規19です。尺はカットの合計で約3分23秒、台詞の間を足して声込み約3分50秒を見込みます。

この回の芯は「昼でも気が抜けない」。あかねと朔奈だけが警戒していて、二人は互いにそれを言わない。最後はあかねの「……もしかして」で終わる。

**リコリスのショートから持ち込む演出ルール**

1. **黒板を、この回の「花びら」にする。** 夜に書く → 同じ構図の朝 → 先輩が足を止める → 夜の回想、と4回同じ物を見せ、時間と不安の変化をこの1枚で運ぶ。
2. **シーンの頭は物の寄りから入り、引きは後に出す。** 寄り→寄り→引きの順にし、引きで全体を見せる前に、視聴者に細部を持たせる。
3. **時間の経過は「同じ構図で、人がいる／いない」で見せる。** v5の「× × ×（夜→朝のホワイト）」と「昼→夜ディゾルブ」は使わず、同ポジ（同じカメラ位置）の差分で飛ばす。
4. **捜査官の顔は後回し。** ベル → 逆光の影 → 足元 → 先輩の顔は「おばあ！」で初めて出す。
5. **異物のインサートは1つだけ。** パン・トング・紙袋の寄りと同じサイズ・同じレンズで、先輩の腰の手帳とバッジを1カットだけ混ぜる。説明はしない。
6. **「見られている」は真俯瞰で見せる。** 先輩が「あの子らは？」と聞く瞬間だけ、店全体の真俯瞰にする（リコリス#04の防犯カメラの俯瞰と同じ使い方）。
7. **内と外は窓・扉・棚の縁を額縁にして、同じ画面に2層で置く。** あかね（内・影）と捜査官（外・光）が、別の空間にいることが常に見えるようにする。

**素材の表記：** 流用＝v5のコマをそのまま使う／修正＝v5の画を使い、台詞・表情・小物を差し替える（i2iの差分）／新規＝新しく生成する。v5のカット番号はv5の字コンテのCUT列に合わせています。
