# EP01 v6 指示書（カット生成・動画化・並べ担当向け）

## 1. この版について
v5を土台に、次の三つで1話を組み直した版です。v5は使いません（このv6に置き換え）。カット番号は**振り直し**（S1-01〜S8-15）。v5の番号は並べ順リストの「v5の番号」の列にあります。
1. **イマジナリーライン**：店＝画面の右、外＝画面の左。
2. **カメラワーク**：付けパン、回り込み、T.U./T.B.、振り、ピン送り、回転、クレーンを、コマ（始点・終点）で描き分けた。
3. **演出のフィードバック**：同じ店がその人にどう感じられるか。言った人より受け取った人を見せる。引きで待たせる。
- 新規に生成するコマ：54コマ（6シート）。前の画像をそのまま使うコマ：148コマ（うち左右反転8コマ）。
- カメラが動くカット：33カット（字コンテの「動画化」の列）。
- 字コンテの尺：約287.8秒（4分47秒）。上映順：S1→S2→タイトル→S3→S4→S5→S6→S7→S8→〈つづく〉

## 2. 画面の方向（イマジナリーライン）
- 外の暁は**右を向いて、左→右へ**進む（店の側へ）。扉の内側のあかねは**左を向く**。扉をはさんで向かい合うので、必ず逆向き。
- 捜査官（S8）は店の側から町へ、**右→左**へ進む。
- 入口の内側から撮るカットは、扉が左、店が右。店内はカウンターの天板を軸に、客席の側（A・C・D・E）から撮る。
- 前の画像のうち、足元・角・後ろ姿など反転しても破綻しないものだけを**左右反転**して使う（紫の行）。S1-04（暁の口元）は、顔が右向きか確認し、左向きなら反転する。

## 3. カメラが動くカットの作り方（今回いちばん大事）
今までの編集版には、キャラについていくパン、回り込み、カットを割らずに顔を移す振り、T.U.がありませんでした。v6では、これを**コマとして生成**し、**動画生成でつなぐ**前提にしています。
1. 9コマのシートで、同じカットの①②③を、同じ場所・同じ人物・同じ光のキーフレームとして生成する。
2. 動画生成（始点・終点フレームを指定できるもの）で、①を始点、②を終点にする（③がある場合は、②→③をもう一本）。プロンプトには字コンテの「動画化」の列をそのまま使う。
3. 動画生成で破綻する場合は、コマを0.3秒のディゾルブでつなぐ（v5までの方法）。付けパンは、コマのあいだを背景だけ横にスライドさせる編集でもよい。

| 動き | 字コンテの書き方 | 主なカット |
|---|---|---|
| 付けパン | 人物は画面のほぼ同じ位置、背景が流れる | S1-01、S1-02、S1-05、S3-09、S4-02、S6-04、S6-11、S8-02 |
| 回り込み | 人物を中心に、カメラの角度だけ変わる | S2-13、S4-04、S6-13 |
| 振り＋ピン送り（カットを割らずに顔を移す） | 構図はほぼ同じ、ピントと向きが変わる | S3-02、S5-03、S6-10、S8-03、S8-09 |
| 振り（視線のパン） | あかねの視線の速さで | S5-11 |
| T.U. / T.B. | ごく遅く（2〜8%） | S1-09、S2-08、S3-01、S3-07、S3-21、S4-05、S5-08、S8-11 |
| 回転 | 傾きが変わる | S1-07（10度→水平）、S7-04（0度→8度） |
| ドリーイン、クレーン | 前進、上昇しながら引く | S1-08、S6-13 |

## 4. 流れの変更（並べるときに守ってほしいこと）
1. **S1・S2：暁の体験からあかねへ渡す**。カメラは暁のそばに置き、足が止まるとカメラも止まる（S1-05）。投函したら内側へ切り、誰もいない入口で鈴の揺れが収まるまで待つ（S2-02）→外で待つ暁（S2-03）→奥からあかね。「どうぞ」のあとは、カメラはあかねに残り、暁が前を通り抜ける（S2-11）。扉に背を預けたあかねへ回り込み、店の光の側の顔でホワイトアウト（S2-13）。
2. **S3：一つの全景→まひるの動作で目を動かす**。手前の朔奈の仕事からピン送りで奥のまひる、振って海凪（S3-02）。「お母さん役」は、二人の後ろから奥の朔奈（S3-07）。海凪はピアノへ向かう背中を付けパンで、途中で止まって「私の分」（S3-09）。
3. **三禁は「人が楽しんでいる動作」**：グラスへ伸びる客の手（S3-12）、リズムを取る客の指（S3-14）、手に身体を預けるステラ（S3-15）。朔奈の写真には寄らない（S3-20）。
4. **S4：身体が居場所を覚えている**。入口から席6まで付けパン（S4-02）→回り込んで、座る暁とコートを直すあかね（S4-04）→暁の画にグラスが入り、「おかえり」は朔奈の声だけ（S4-05）。朔奈の顔には切らない。
5. **S5：カメラも待つ**。問いかけの2ショットを保持（S5-04）→「嫌です」はT.U.（S5-08）→あかねの視線のパンで、客席から仲間へ「思いますか？」（S5-11）→仲間を見るが、まだ笑わない（S5-12）。
6. **S6：ピアノの音が先、身体が後**。最初の一音→あかねに付けパンで、手の力が抜け、足取りが弾み、鼻歌（S6-04）。SDのあいだもピアノは続く。「はい！」のあとは仕事に戻る（S6-11）。上昇しながら引いて全景（S6-13）。
7. **S7：引きの中で待たせる**。暗い全景は顔を切り替えず保持し、まひるの台詞は声だけ（S7-09）。止まった人たちと、まだ動くステラを同じ画で（S7-12）→全景の中であかねだけが動く（S7-14）。
8. **S8：同じ場所の、もう一つの見方**。最後の黒板は、冒頭で暁が見た黒板と同じ構図（S8-11＝S1-02②）。
