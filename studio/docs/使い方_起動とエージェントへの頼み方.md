# 使い方：起動とエージェントへの頼み方

## 1. 最初に1回（Windows の PC）

必要なもの：Python 3.11 以上、ffmpeg（PATH に入っていること）、Git。

1. このリポジトリを PC に clone する（またはいつもの場所に pull）。
2. `studio\setup.bat` をダブルクリック。必要なものが `studio\.venv` に入り、キャラと舞台の設定（`月灯_vault/06_設定`）が作られる。
3. 生成物と DB の置き場所を変えたいときは、環境変数 `TSUKI_DATA` を設定する（例：`D:\月灯スタジオ\data`）。既定は `studio\data`。
4. 鍵（あとで）：`HAMSTER_API_KEY` `HAMSTER_BASE_URL` `HAMSTER_PROJECT_ID`、`RUNWAYML_API_SECRET`、`BLENDER_EXE`。

## 1.5 9話の仮制作を載せる（動作確認）

9話を「制作中」の状態で月灯スタジオに載せる（設計 G1 確認待ち、仮Vコンのシート分け、ショット 18本、点検済みのプロンプト）。

```
studio\.venv\Scripts\activate
python studio\seeds\EP09_仮制作.py --refs "C:\Users\kaka\Desktop\e002素材\（参照画像のフォルダ）"
```

`--refs` には e009 で使った参照画像（`akane_moto_260909.png`、`月明かり店内.png` など）が入ったフォルダを指定する。なくても載る（参照は「足りない」と表示される）。
載せ直すときは `--reset`。画面の「話数 → EP09 → 設計」と「レビュー → エージェントの返答を確認」から見る。

## 2. 毎回の起動

`studio\start.bat` をダブルクリック → ブラウザで http://localhost:8765 が開く。
画面を閉じても、黒いウィンドウ（サーバー）を閉じるまでは動いている。

## 3. エージェントへの頼み方（3通り）

どの方法でも、エージェントは同じ道具（MCP の `tsukiakari-studio`、または `python studio/cli.py`）と同じ手順（`CLAUDE.md`、`.claude/skills/tsukiakari-studio/SKILL.md`）で動く。**依頼は画面の「依頼」に積んでおく**と、どの Claude が取っても二重に進まない。

### A. この PC の Claude Code に頼む（いちばん速い）

1. `start.bat` で月灯スタジオを起動しておく。
2. リポジトリのフォルダで Claude Code（ターミナル、またはデスクトップアプリ）を開く。`.mcp.json` に月灯スタジオの MCP が登録してあるので、最初に許可を聞かれたら許可する。
3. 話しかける：「依頼を進めて」「EP09 のドラフトを全部出して」など。画面の「依頼」→「この PC の Claude へ」で出る依頼文を貼ってもよい。
4. 進み具合は画面の「編集（ライブ）」の右側と、トースト（右下）にリアルタイムで流れる。

Premiere / After Effects を画面操作させたいとき（パネルで扱えない操作）も、この方法を使う（Claude のデスクトップアプリの computer use）。

### B. Claude Desktop（チャット）に頼む

Claude Desktop の設定（開発者 → MCP サーバーの設定）に次を足す（パスは自分の clone の場所に直す）：

```json
{
  "mcpServers": {
    "tsukiakari-studio": {
      "command": "C:\\path\\to\\claudeclowdtest\\studio\\.venv\\Scripts\\python.exe",
      "args": ["C:\\path\\to\\claudeclowdtest\\studio\\mcp_server.py"],
      "env": { "TSUKI_DATA": "C:\\path\\to\\claudeclowdtest\\studio\\data" }
    }
  }
}
```

チャットで「月灯スタジオの依頼を1つ進めて」と頼む。ドラフトの確認用の画像（コンタクトシート）もチャットで見られる。

### C. クラウドの Claude（claude.ai/code など）に投げる

クラウドの Claude からは、この PC の月灯スタジオに**トンネル越し**につなぐ（生成物と DB は PC に1つだけ置く）。

1. 鍵を決める：`set TSUKI_TOKEN=長いランダムな文字列`（人に見せない）。
2. `studio\start_remote.bat` で、画面（8765）と MCP（8766）を起動する。
3. トンネルで MCP を外に出す。例：`cloudflared tunnel --url http://localhost:8766` → 出てきた `https://…trycloudflare.com` を控え、`set TSUKI_PUBLIC_URL=その URL` にしておくと依頼文に入る。
4. 画面の「依頼」→「クラウドの Claude へ」で依頼文をコピーし、クラウドの Claude に貼る。接続先は `https://…/mcp`、ヘッダーは `Authorization: Bearer <鍵>`。
5. クラウドの Claude はリポジトリ（vault と手順）を clone して読み、作業は MCP 経由で PC の月灯スタジオに入る。

注意：トンネルを開けている間は、鍵を知っている人なら誰でも月灯スタジオを操作できる。作業が終わったらトンネルとウィンドウを閉じる。鍵はときどき変える。

## 4. Premiere / After Effects のパネル（動作確認から）

入れ方は [studio/premiere/README.md](../premiere/README.md)。最初の確認：

1. `start.bat` で月灯スタジオを起動。
2. Premiere を開き「ウィンドウ → エクステンション → 月灯スタジオ」。パネルの記録に「premierepro 25.x とつながりました」と出れば ExtendScript まで届いている。After Effects でも同じ（「aftereffects …」）。
3. エージェント（または自分）で `python studio/cli.py adobe-test` → パネルが命令を取り、`adobe-status` に結果が出れば往復できている。After Effects は `adobe-test --host aftereffects`。
4. 小さい話数で `pr-build EP09` を試し、シーケンスができるか、クリップの長さが合うかを見る。だめだったときは、パネルの記録と `adobe-status` の結果をエージェントに渡せば直せる。
