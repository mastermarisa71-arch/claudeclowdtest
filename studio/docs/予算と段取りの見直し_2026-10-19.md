# 予算と段取りの見直し（2026-10-19）

監督から受け取った実際の単価で、1話（約3分）の費用・時間・監督の手間を引き直した。

## 単価（HAMSTER / Seedance 2.5）

| 解像度 | 15秒 | 1秒あたり |
| --- | --- | --- |
| 480p | 250円 | 約16.7円 |
| 720p | 550円 | 約36.7円 |
| 1080p | 1,400円 | 約93.3円 |

15秒以外は未確認。長く作った方が割安の見込みがあるので、テストの回で 30秒の値段を確かめる（`stats` に実績が出る）。安ければショットを長めに組む方が得になる。

## 1話の費用の見込み（3分＝180秒）

| 工程 | 量（作り直し率込み） | 費用 |
| --- | --- | --- |
| 9コマ仮Vコン | 13枚 × 1.3 | 約700円（単価は仮） |
| 480p ドラフト | 180秒 × 1.5 ＝ 270秒 | 約4,500円 |
| 1080p 本番 | 180秒 × 1.1 ＝ 200秒 | 約18,500円 |
| 仮の声・効果音・劇伴（Runway） | 約100回 | 約1,000円（単価は仮） |
| **小計** | | **約25,000円** |
| 声優の声で本番を作り直す | 台詞のあるショット 約120秒 | 約11,000円 |
| **声優込み** | | **約36,000円** |

- 5万円に対して、ふつうに進めれば半分、声優の作り直しを入れても7割ほど。残りの約1.4万円が、ドラフトの作り直しが増えたとき（作り直し率 1.5 → 3 で +4,500円）や、本番のやり直しの余白になる。
- **いちばん大きいのは 1080p 本番**（全体の7割）。本番のやり直しを減らすことが一番効く：
  - ドラフトで決めきってから本番にする（すでにツールで強制している）。
  - 声優の声が本番より先に届くなら、**最初から声優の声で本番を作る**（作り直しの約1.1万円がなくなる）。届く時期を本番の順番に合わせる価値がある。
  - 口が大きく映らないショットは、声優の声で作り直さず編集で合わせる。
- 720p は使わない（ドラフト 480p と本番 1080p の2段で足りる）。
- テストの回（最初の数話）は、作り直し率が高くなる前提で `--test` にし、実績を `stats` で取って、2話目以降の作り直し率と単価をこの表に戻す。

## 止まる時間（待ち）

まだ実績がないので、テストの回で測る。ツールは次を自動で記録する（画面「実績」・`stats`）：

- **生成の待ち**：送ってから出来上がるまで（工程ごとの平均と合計）。
- **監督のレビューまで**：出来上がってから監督が最初に見るまで。

段取りでの扱い：

- ドラフトは**全部まとめて夜に送る**（1日目の夜）。生成の待ちを監督が寝ている時間に重ねる。
- 1080p 本番は採用が決まった順に送り、待っている間に次のショットの直しを進める。
- 監督の待ち（エージェントが関門で止まる時間）が長い工程は、`stats` の「レビューまで」で分かる。長ければ関門の時間を固定する（例：朝と夕方に30分ずつ）。

## 監督の時間（見直し）

以前の見込み（3〜4時間）より、Premiere での共同編集の分だけ増える。そのかわり、XML の往復と確認待ちがなくなる。

## レビューを速くする仕組み（今回追加）

- **音声入力**：すべての入力欄に 🎤。「修正、あかねの向きが逆で表情が硬い」と話すと、判定＝修正、観点＝配置・左右／表情、コメントが自動で入る。
- **キーで流す**：「AIが通したもの」で 1＝良い、2＝採用、3＝話して直し。
- **Premiere のパネル**：手直しのあと「AIに渡す」＋ひとこと（音声入力可）だけで、エージェントに渡る。

## LLM（Claude）の使用量

円の予算とは別枠だが、使用量の上限には効く。今の抑え方：ブリーフは要点だけ、セルフレビューはドラフトから抜いた6フレームの画像で見る、定型の点検はツール（`shot-shoot` の点検）に任せる。テストの回で、どの工程で多く使ったかを見て、軽いモデルに回せる作業（セルフレビューの一次確認など）を決める。
